How To Flash

  1. Open this page in Chrome or Edge on Windows, macOS, or Linux.
  2. Connect the CYD over USB using a cable that supports data.
  3. Click the install button and pick the device serial port.
  4. If prompted, allow erase and install so all firmware parts are written correctly.
  5. Wait for the board to reboot, then open the setup portal on the device.

Troubleshooting

  • If no serial port appears, swap the USB cable first. Power-only cables waste time.
  • If the browser says the port is busy, close serial monitors, PlatformIO, Arduino IDE, or any terminal using the board.
  • If flashing fails mid-way, reconnect the board and retry with the install button again.
Firmware files are published from GitHub Pages using the same manifest consumed by the browser flasher.
